# README Update Prompt for GitHub Copilot

This is a sample prompt file that should be placed at `.github/copilot-prompts/README_UPDATE.md` in your repository.

The workflow will read this file and use GitHub Copilot CLI to generate or update your README.md based on these instructions.

## Instructions for Copilot

Please update the README.md file with the following sections and information:

### Project Overview
- Provide a clear, concise description of what this project does
- Explain the main purpose and goals of the project
- Include any relevant badges (build status, coverage, license, etc.)

### Installation
- Document how to install or set up the project
- Include prerequisites and system requirements
- Provide step-by-step installation instructions
- Include code examples for common package managers (npm, pip, etc.)

### Usage
- Explain how to use the project with clear examples
- Include code snippets demonstrating common use cases
- Document configuration options and environment variables
- Provide examples for both basic and advanced usage

### API Documentation
- List and describe all public APIs, classes, or functions
- Include parameter descriptions and return values
- Provide code examples for each major API endpoint or method

### Features
- List key features and capabilities
- Highlight what makes this project unique or useful
- Include any planned features or roadmap items

### Contributing
- Explain how others can contribute to the project
- Reference CONTRIBUTING.md if it exists
- Include information about coding standards or style guides

### License
- Specify the project license
- Link to the LICENSE file if it exists

### Support
- Provide information on how to get help or report issues
- Include links to documentation, issue tracker, or community channels

---

**Note to developers**: Customize this prompt based on your project's specific needs. The more detailed and specific your instructions, the better the AI-generated documentation will be.
